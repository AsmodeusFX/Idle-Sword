## 一、设计目标

当前 `SwordSkill.csv` 的 15 个技能是占位样例：5 种硬编码类型按固定轮换循环，`power/duration/cooldown` 高度雷同，仅名字不同，技能之间没有实质差异。本轮目标：

1. 让 15 个技能**各有明确定位**，而非同一数值的换皮。
2. 在**沿用现有 5 类基础机制**的前提下，通过「次级效果」制造差异（不引入组件化系统）。
3. 为每个技能补上**技能说明文字**与**可参数化的范围/效果参数**。
4. 保持境界递进主题（炼气 → 筑基 → 金丹 → 元婴 → 化神）。

动画与伤害反馈、剑意与技能的按元素绑定关系不在本轮（见第八节）。

## 二、基础机制（沿用现有 5 类）

| 类型 | 代号 | 现有行为（`GameSession` 中已实现） |
| --- | --- | --- |
| 弹丸 | projectile | 发射飞行物命中目标造成伤害；**具体怎么飞由 `trajectory` 决定**（直线 / 头顶悬浮后追踪 / 敌人上空垂直下落 / 弧线追踪），数量由 `projectile_count` 决定，见第四节 |
| 定点 | target | 锁定目标，延迟 `duration` 秒后结算伤害 |
| 地面 | ground | 生成持续范围，每 0.6 秒对范围内敌人造成伤害 |
| 增益 | buff | 自身短时增益，施放时回一次 5% 气血。配置里 `power != 1` 才占用共享的伤害倍率窗口；`power = 1` 的纯功能向增益（攻速/暴击）只持有自己的计时器，不会把正在生效的伤害增益重置掉 |
| 召唤 | summon | 生成召唤物，周期自动发射弹丸攻击 |

### 普通攻击（不属于剑诀）

角色默认拥有一手平射飞剑：每 `fightattr.basic_interval`（1 秒）向最近的合法目标发射一柄飞剑，伤害 = `最终攻击 × basic_power`，射程 `basic_range`。它照常吃暴击伤害与攻速增益（占 `Battle.Cooldowns` 的一个键，因而复用统一的冷却衰减），但**不触发**「暴击缩短一个随机技能的冷却」，也不在 `Config.Skills` 里——它不是第 16 个剑诀，不参与技能书、剑意强化与技能预览的逐个对照。

真诀的触发概率就是在它出手的那一刻摇的：见第三节末与 [../data/fields.md](../data/fields.md) 的「触发概率（真诀）」。

## 三、次级效果目录（15 种）

次级效果附着在基础机制之上，用「类型 + 强度 + 持续」三要素描述。分三类：

### 状态类（作用于目标，9 种）

| 效果 | 代号 | 含义 | 强度字段含义 | 意境 |
| --- | --- | --- | --- | --- |
| 减速 | slow | 降低目标移动速度 | 减速比例（0～1） | 寒霜束缚 |
| 寒冷 | chill | 与减速同源的移速下降，另带一层「受寒气所侵」的状态 | 减速比例（0～1） | 冰封剑气 |
| 眩晕 | stun | 目标无法移动、无法攻击 | 无强度（仅持续） | 雷击麻痹 |
| 灼烧 | dot | 每秒造成额外伤害 | 每秒伤害倍率 | 烈焰灼身 |
| 易伤 | vulnerable | 目标受到伤害提高 | 增伤比例（0～1） | 破甲穿空 |
| 吸血 | lifesteal | 造成伤害按比例转化为自身气血 | 吸血比例（0～1） | 血炼剑意 |
| 斩杀 | execute | 对低气血目标造成额外伤害 | 气血阈值（0～1） | 诛邪锁魂 |
| 护盾 | shield | 为自身生成吸收伤害的护盾 | 护盾量（相对攻击的倍率） | 剑罡护体 |
| 回血 | regen | 每秒恢复自身气血 | 每秒恢复比例（0～1） | 归元调息 |

### 自身增益类（作用于自身，2 种）

| 效果 | 代号 | 含义 | 强度字段含义 | 意境 |
| --- | --- | --- | --- | --- |
| 攻速 | haste | 冷却流逝加快，出手更频 | 提高的比例（3 = +300%，即 ×4） | 仙风云体 |
| 暴击 | crit_reduce | 暴击率提高；暴击时缩短一个随机技能的冷却 | 暴击率**绝对**加成（0.3 = +30 个百分点）；缩短秒数走 `secondary_extra` | 醉仙望月 |

> `haste` **只加速输出类剑诀与剑灵**的冷却，不加速增益类剑诀：否则 15s 冷却 / 6s 持续的增益会在持续期内转好，等于自己给自己减冷却，变成 100% 常驻。
> `crit_reduce` 的缩短目标只从"已习得、当前冷却 > 0、且**不是增益类**"的技能里抽，没有候选就什么都不做；且**每次施法最多触发一次**（由该次施法的第一支弹丸负责）。暴击本身是逐弹丸摇的，多发齐射一轮 3～5 支——不限制的话触发密度放大数倍，还会不断给增益减冷却，形成"暴击 → 增益来得更勤 → 出手更快 → 更多暴击"的正反馈（实测攻速覆盖率会从标称的 40% 自涨到 53%）。

### 目标/效果参数类（改变命中方式，2 种）

| 效果 | 代号 | 含义 | 强度字段含义 | 意境 |
| --- | --- | --- | --- | --- |
| 穿透 | pierce | 弹丸直线贯穿沿途所有敌人，逐一对每个命中者结算伤害 | 无强度 | 剑气贯穿 |
| 多重 | multi | 同时锁定并攻击多个目标 | 目标数量 | 疾风分袭 |

> 说明：`pierce`（直线贯穿）与 `multi`（同时锁定多目标）语义不同——前者是单发贯穿多个，后者是分裂为多份各打一个。二者都改变「命中方式」，故单列。两者**当前都没有在役技能**（恒穿透已由 `line_pierce` 形态承载），代码分支保留。

### 后加的两条（不在上表的三分类里）

| 效果 | 代号 | 含义 | 强度字段含义 | 载体 |
| --- | --- | --- | --- | --- |
| 影分身 | mirror | 持续期内本体每放一个剑诀，身后的分身同步再放一份 | 继承比例（0.7 = 七成，`≤ 1`） | 19 剑二十三（必须 `kind = buff`） |
| 利用状态 | bonus_vs_state | 对**携带任意状态**的目标增伤，**不消耗**状态 | 增伤比例（必须 > 0） | 10 斩鬼神（+30%） |

两条的完整语义见 [../data/fields.md](../data/fields.md) 的「影分身」与「利用状态」两节。

## 四、字段扩展方案（实现阶段落地，文档先定）

`SwordSkill.csv` 拟新增 5 个字段（定稿后同步 `headers.json`、`fields.md`、`GameConfig.cs` 校验）：

| 新增字段 | 类型 | 含义 |
| --- | --- | --- |
| `description` | string | 技能说明文字，用于界面展示 |
| `secondary` | enum（可空） | 次级效果类型，取第三节的次级效果之一；空表示无 |
| `secondary_value` | number | 次级效果强度（`multi` 为目标数、`stun`/`pierce` 可忽略） |
| `secondary_duration` | number | 次级效果持续时间（秒）；瞬发/参数类可为 0 |
| `aoe_radius` | number（可空） | 范围半径（ground 类专用）；0 或空表示单体，默认沿用当前 220 |

现有字段 `cooldown / range / power / duration / max_level / cost / cost_growth` 语义不变。

### 飞行形态（`trajectory`）与编排参数

弹道类技能的表现差异不再靠"一个技能一套硬编码"，而是"形态 + 正交旋钮"。

| 形态 | 含义 |
| --- | --- |
| 空 / `bolt` | 直线追踪单体。剑灵弹丸等未指定形态的弹道也走这条 |
| `line_shot` | 肩侧平射、不追踪，命中路径上**最先遇到**的敌人即结算并销毁；配合 `pierce_chance` 有**一次**概率穿透的机会 |
| `line_pierce` | 身前贯穿，命中沿途每个敌人一次，越界消失（穿透由形态自带，不占次级效果列）。剑气流云壁（贴地弧形剑气）与天剑（横空斩出的巨剑）用它 |
| `sky_drop` | 敌人上空**固定剑阵**垂直落剑，X 冻结不追踪，落地按半径结算（可命中重叠单位） |
| `arc_homing` | 弧线追踪；弧度区间带负值即为从下方掠过 |
| `hover_homing` | 头顶悬浮后追踪。**当前无技能使用**，作为词汇表保留 |

配套参数（`SwordSkill.csv` 尾部的弹道列，字段含义见 [../data/fields.md](../data/fields.md)）：

| 字段 | 作用 |
| --- | --- |
| `projectile_count` | 单次出手的弹数 |
| `hover_time` | 起飞前在空中停留的秒数（悬浮蓄势／浮现／天降停留） |
| `arc_min` / `arc_max` | 每支弧高的随机区间（可为负，下限 -60，上界 300） |
| `speed` | 弹道速度，0 = 默认 1500；**只作用于剑诀**，宠物弹与召唤弹不受影响 |
| `spread` | 弹群排列间距：`sky_drop` 为落点横向间距（参与判定），其余形态为表现层排列间距 |
| `volley_interval` / `volley_jitter` | 多发之间的发射间隔与随机抖动 |
| `spawn_jitter` | 出生高度的随机幅度（表现） |
| `pierce_chance` | `line_shot` 首次命中的概率穿透（0～1）：一次判定机会，穿透后同一支剑永久关闭该机会 |
| `secondary_extra` | 次级效果的附加参数（当前为 `crit_reduce` 的缩短秒数） |

配套规则（改了要同步 `fields.md` 与 `GameConfig` 校验）：

- 多发**各自选敌、尽量不重复**（敌人不足才循环重复）；`sky_drop` 例外，以最近敌人为阵心按 `spread` 铺开，**与敌人数无关**。没有合法目标时不空放、不消耗冷却。
- `power` 是**每支**的威力，单次施法总伤 ≈ `power × 命中数`；多发技能要相应下调 `power`。`sky_drop` 的落点判定半径复用 `aoe_radius`（此时必须为正，不回退 220）。
- 追踪目标中途死亡：**不重选目标**（多发齐射会成批改道），但仍把这一程飞完——朝它**最后所在的位置**（`CombatEffect.TargetX`）走，到点即散，不再造成伤害。早先的写法是沿发射方向一直飘到出界，落到画面上就是"剑芒贴着地面平行右移一段才消失"，读起来像脱靶。
- 弧度与出生高度抖动都由逻辑层在发射时**一次摇定**存进效果供表现层只读；表现层逐帧重摇会抖动且破坏自检可复现性。
- 落点这类**参与判定**的量（`sky_drop` 的阵心与间距）必须由 Core 算进 X；表现层再自己偏移就会"看着没打中却掉血"。
- 表现层按形态分流绘制，不按技能 ID：以后同类形态的新技能只改 CSV。

已陆续替换进 `Config/Tables/SwordSkill_Retired.csv` 的技能（不参与加载，供日后改形态复用）：01 御气飞剑（pierce）、06 疾风剑（multi 3）、11 流火剑（dot）、04 护心剑罡（shield）、09 归元护法（regen）、02 落星诀、07 天雷引（stun）、12 破云诀（vulnerable）、05 唤剑影 / 10 太虚剑侍 / 15 诛邪剑灵（三个 summon，最后一个还带 execute）、03 青莲剑阵 / 08 霜华剑域 / 13 焚天剑阵（三个 ground 剑阵）、**16 剑侍**（跟随召唤，机制留给以后的剑灵系统）。

**在役/退役的变动**：次级效果 `stun`（07 御雷真诀）、`execute`（17 天剑）在境界重排一轮复活；`mirror`（19 剑二十三，影分身）与 `bonus_vs_state`（10 斩鬼神，利用状态）是后来新增的两条。**本轮 `vulnerable` 下线**：它原本由 18 大庚剑阵承载，该技能改成爆炸类的**苍穹剑陨**后不再挂状态——用户明确"易伤不该占着这个技能的位置，将来由**剑意**授予某个技能分支"（`SwordUpgrade.effect` 目前只有 `damage_percent` / `inherit_percent`，扩展它属于另一轮）。当前**没有在役技能使用**的条目：次级效果 `pierce` / `multi` / `shield` / `regen` / **`lifesteal`** / **`vulnerable`**；形态 `hover_homing`；以及类别 `summon`（跟随召唤的剑侍已归档，机制留给以后的剑灵系统）。代码分支全部保留并在 `tests` 里用内存改配置维持覆盖。

由此带来的定位变化：炼气失去唯一穿透清怪；`vulnerable` 随大庚剑阵一起退役，当前没有在役载体（代码与自检覆盖保留）——前排肉那条轴因此只剩 17 天剑的 `execute`，但**没有断**。炎系灼烧的载体曾一度空缺，已由**焚天剑诀**补回。

## 五、十五剑诀设计

> 数值均为**草案初值**，用于体现定位与节奏，**非最终平衡曲线**（见第七节）。伤害公式沿用现有：
> `DMG1 = 最终攻击 × power × (1 + 0.15×(等级-1) + 剑意加成) + skill_flat`，再走 DMG3
> （通用增伤 × 暴击 × BD 增伤 × 易伤）。**完整口径见 [combat.md](combat.md)**——
> `power` 与剑意属于 DMG1（技能自身的定义），斩杀 / 利用状态 / 倍率窗属于 DMG3 的 Build 乘区。
>
> **刻度重定一轮**：标准怪 HP 从 45 抬到 88（= 0.5 SU → 1 SU），所以除三个增益类外的 `power` **整体 ×2**，让"几次施法清一波"的手感不变。同时御剑术改成 1 支 × power 3.5（1 支 = 1 SU）、仙风云体术 `haste` 3 → 0.25。口径与推导见 [balance_ttk.md](balance_ttk.md)，**改任何一个 `power` 都要回去看那份文档**。

> 技能书序 = `SwordSkill.csv` 的行序（境界内按行序显示，见 `Pages.cs`）。当前顺序：
> 炼气 御剑术 / 仙风云体术 / 青元剑芒，筑基 万剑决 / 天剑 / 剑罡护体，
> 金丹 焚天剑诀 / 寒冰龙卷 / 御雷真诀，元婴 苍穹剑陨 / 醉仙望月步 / 剑气流云壁，化神 剑二十三 / 斩鬼神 / 诛仙剑阵。
> `id` 保持稳定不变，方便存档与剑意表引用（上移/下移的三式沿用了原 id 与成本，新技能用 `skill_17`–`skill_19`）。
>
> 「触发」列＝`trigger_chance`：非 0 表示该剑诀不自动释放，改为普攻出手时按概率触发；「冷却」对它即最短触发间隔。

| 01 | 御剑术 | projectile | 1.2 | 950 | **3.5** | 0.8 | 无（`line_shot` ×**1**，间距 28） | 剑诀御剑，飞剑自肩侧横射而出，击中即散。 |
| 04 | 仙风云体术 | buff | 15 | 950 | 1.0 | 6 | haste **+25%** / 6s | 仙风云体，周身真气鼓荡，出手快如疾风。 |
| 11 | 青元剑芒 | projectile | 1.3 | 950 | **1.45** | 0.9 | 无（`arc_homing` ×3，弧高 -50～140、错时 0.1s、速度 1200，`targeting` **`lowest_hp`**） | 青元剑气激射，划出弧光索敌，专收残血之敌。 |

- 御剑术**不再开局附送**：玩家要在技能页点「习得」花 30 灵钱学它。开局只有普攻（25 伤害，标准怪 88 HP = 3.5 下），学完一支剑就秒一只——这个对比就是"第一次花灵钱"要说清的事。
- `power 3.5` 是**刻度锚**而不是手感值：它让"1 支 = 1 SU"（1 SU = 该关标准怪 HP）。剑支数（1 → 5）才是它的成长轴，见 [balance_ttk.md](balance_ttk.md) 第 4 节。改这个数要连着跑 `tools/BalanceCurve`。
- 穿透已从御剑术身上拿掉（命中即散），**穿透留给后面的技能**；御剑术后期改由剑意提供 `pierce_chance` 概率穿透，且只有第一次命中可触发。
- 仙风云体术的攻速只加速**输出类剑诀与剑灵**的冷却，不加速增益类——否则它自己 15s 冷却 / 6s 持续会在持续期内转好，变成 100% 常驻（见第四节）。普攻占的是一个普通冷却键，因此**吃攻速**。
- 仙风云体术 `haste` 从 +300% 降到 **+25%**（冷却流逝 ×1.25，等效缩短 20%）：它是全局乘区、普攻也吃，炼气档不该给满。文案统一写"冷却流逝 +X%"，别和"冷却缩短"混用——两个口径差 4 倍。
- **青元剑芒与御剑术的差异是"打谁"，不看数值**：御剑术是 `line_shot` ×1，命中直线上**最先遇到**的那只——**怼眼前**的；青元剑芒是 3 支追踪剑、`targeting = lowest_hp`，取**射程内血量最低的 3 个**——**收割残血**。场上不足 3 只时三段全部重复打同一只（`TargetsWithRepeats` 的现成行为），所以**打 BOSS 不吃亏**。3 段还多两次判定，更吃暴击与斩杀。同档的两个技能，一个"打最前的"、一个"打最脆的"。
- **"收割"要成立，必须先修掉"白飞"**：追踪弹有飞行时间，而它锁的又正是**最快死**的目标——目标半路被别的技能打死时，原先这一发**一次伤害都不结算**（实测确认"伤害大部分丢失"）。现在改成**飞完这一程再落点重索敌**：先沿原轨道飞到目标最后所在的位置，再在 80 单位内挑**血量最低**的合法敌人接着追，**弧度取反**——画面上是一道反向的弧，两段连起来像个波。挑最低血而不是最近的，正是为了契合收割：**落地那一刻谁最脆就追谁**。索不到敌就消散、本次伤害丢失（有意，不做兜底命中）。同一个补救也覆盖 `target` 类（御雷真诀 / 斩鬼神 的长冷却大招不会白白打空）。见 [../data/fields.md](../data/fields.md) 的「目标中途死亡的补救」。

- **万剑决**是范围定位：`sky_drop` 的剑阵以最近敌人为阵心、按 `spread` 铺开，**与敌人数无关**，所以人群里比单体剑好用。它和炼气的御剑术正好是「面 vs 点」。
- **天剑**是**横向贯穿**：一柄巨剑横空斩出、沿途每个敌人各结算一次，再带 `execute`（目标掉到三成气血以下伤害翻倍）。它补的是**"打成一排 / 破前排"**这个维度，并把这条功能从金丹**提前到筑基**；同时**让开了"对最近的一只打一发"那个位置**——原来它和御雷真诀、斩鬼神三者撞在一起。代价是筑基失去单体爆发，由金丹的御雷真诀承担；而持续单体一直由炼气的御剑术顶着。
  - **2026-10-04 实测修正**：它一度是全游戏最大的一笔输出（一场 737 秒的战斗里占 **39%**）——因为 E1 表把 `line_pierce` 记作单体（`N1 = 1`），而实战里**一次出手平均贯穿 18.6 只**。改法保住身份：**冷却 6 → 18、`power` 19.68 → 9**（单发仍是御剑术的 2.6 倍），从"频繁扫一排、一下就清场"变成"偶尔来一发、贯穿一整排"。口径的根因见第八节的注与 [balance_ttk.md](balance_ttk.md) 第 9 节第 9 条。
- **剑罡护体**（原「万剑归心」，从"吸血"改成"**护盾 + 环绕飞剑还手**"）：实测下来**吸血来得太晚**——以横版战斗的距离关系，角色开始掉血时就说明敌人已经贴脸了，这时候回血帮不上大忙；**护盾是"先挡住"，时机对得多**。
  - 护盾走现成的 `shield` 次级效果（`HurtPlayer` 先扣 `_shield` 再扣血），复用退役的护心剑罡那套半透明护罩绘制。
  - **环绕飞剑**是护盾期间的一条全局规则：每 `guard_interval`（0.8 秒）向 `guard_range`（400）内最近的合法敌人射出一柄小剑，威力 = 攻击 × `guard_blade_power`（1.2）。三个参数都在 `game_settings.csv`。这样"护盾只在挨打时才有用"这条缺点被补上了——护盾负责挡，飞剑负责还手。
  - **出手范围（400）与剑诀射程（950）是分开的两个值**，这一点踩过坑：一度把它们压成同一个（射程 400 当近身范围），结果**远程怪在场时增益根本放不出来**，预览页更是"什么都没有"——靶子固定在 520，射程压到 400 就永远没有合法目标。`range` 管的是"能不能施放"，`guard_range` 管的是"飞剑够不够得着"。
  - 连带：`lifesteal` 因此**没有在役载体了**（回到死配置，代码与自检覆盖保留）。
- **跟随召唤的剑侍已归档**：Core 的 `summon` 路径（锚在身后、每秒发一枚弹丸）与表现层的位次分配都完整保留，机制留给以后的剑灵系统，见 [skill_realms.md](skill_realms.md)。

### 金丹 · 元素引入（炎 / 霜 / 雷）

原来的**元婴三式下移**到金丹，作为元素属性的引入点。元素**不新建字段**，直接由现成的 `secondary` 承载：**炎 = `dot`、霜 = `chill`、雷 = `stun`**。

三式曾是**真诀**（不自动释放、每次普攻各摇一次概率），实测下来"整层不可控、成长反馈不明显"，于是**只留御雷真诀一个真诀**，焚天剑诀与寒冰龙卷改回**固定冷却**——玩家花 1800 灵钱解锁一整个境界，拿到的该有"我说了算"的手段。

| # | 名称 | 类型 | 出手 | 射程 | power | duration | 次级效果 | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 02 | 焚天剑诀 | projectile | **固定冷却 6s** | 950 | **3.07** | 0.5 | dot 25%/s / **5s**（炎，`sky_drop` ×1、落点 120、停留 0.25s、**`targeting = farthest`**） | 召唤一柄火焰剑自敌人上空坠落，落地后化作一片火海，灼烧其中的敌人。 |
| 12 | 寒冰龙卷 | **ground** | **固定冷却 10s** | 950 | **2.93** | 4 | chill 减速 25% / 5s、**`gather` 60**（霜，落点半径 240） | 挥出寒冰剑气凝成龙卷，卷住阵中之敌并拖向风眼，沿途之敌受创且被寒气所侵。 |

- **本档只留一个真诀**（御雷真诀），理由见上。
- 焚天剑诀是「天降火海」：`sky_drop` + `dot` 时落地不做一次性结算，改为在落点留下一片寿命 **5 秒**的火海，每 0.6 秒结算一次并刷新灼烧（见 [../data/fields.md](../data/fields.md)）。
  - **落点规则是 `targeting = farthest`（射程内最靠前的那只）**，不是最近的那只。理由：怪从右边来，那条路是必经之路——落在最靠前的位置等于铺在"迎宾位"，后面进来的都要穿过去；落在最近敌人身上等于落在脚边，怪几乎立刻就走过它了，收益最低。
  - **它是本档唯一的缺口**——`hits = ground`，在空袭 / 妖潮波会整个哑火，靠元婴档的苍穹剑陨补。
- **寒冰龙卷是聚怪技能**（本轮从"推出去的平射贯穿"改过来）：形态由 `line_pierce` 换成 **`ground`**，于是"在敌人位置生成"是现成的——`ground` 的落点本来就是选中目标的 X，不需要新形态。
  - 聚怪靠新开的 **`gather`** 列（`knockback` 的反向孪生，见 [../data/fields.md](../data/fields.md) 的「吸附」）：每次命中把目标朝**风眼**拉近 `gather` 的距离，**取 `min` 所以收敛到中心就停**，不会来回弹。
  - `gather = 60` + `ground` 每 0.6 秒一跳 ≈ **100 单位/秒**的吸力，比青苔妖 155 的移速小——读作"聚拢并拖着走"，而不是钉死；配上它自带的 `chill`（减速 25%）正好压得住。
  - 它是**与苍穹剑陨咬合**的那一半：龙卷把怪捏到一处，剑陨才炸得满。
  - `hits` 留空（= both）：它是落在地上的力场，但不该只打地面——注意别把 `hits` 与 `kind` 弄混。
  - **"靠剑意铺出多个龙卷"留给 `SwordUpgrade.effect` 词汇表扩展那一轮**，本轮记待办。
- 御雷真诀是三者里唯一的高单体爆发，也是全名单**仅剩的真诀**。期望出手周期 = `冷却 + 1 ÷ 触发概率`（冷却未就绪时 `RollTriggerSkills` 直接跳过，所以是"先等冷却、再等摇中"）。
  - **2026-10-05 收尾修正**：触发概率 0.10 → **0.30**（周期 15 → 8.3 秒）。`power` 68.33 → **137** 是同一轮**分级**时按金丹水位提上来的，这次没再动它。理由：实测里它**垫底（2%）**，用户点名"绝对需要提升，还是概率问题"——而它的 raw 有 **88% 是溢出**（每发打掉 4610，只有 552 算数），提概率只能按"每分钟多杀几只"线性改善。
  - ⚠️ **看它要看 raw（有效 + 溢出），别只看"有效"那一列**：它一次能打掉的血被普通怪的气血上限卡住了。**真正的舞台是 BOSS / 裂隙**——那里目标气血厚，溢出才被吃满。
- **护栏（保留）**：功能性技能（控场 / 减速 / 增益）的触发概率要有上限——高频触发会把"控制"变成"常驻"。寒冰龙卷曾经试过固定 70%（冷却一好几乎必放）与"15% 起、逐次累加"，最终直接回到**固定冷却**：`10 秒冷却 / 5 秒减速` = **50% 覆盖率，是写在配置里的确定值**，比"概率"更好读也更好调。与「攻速不加速增益类剑诀」是同一条思路。

- **苍穹剑陨**（原「大庚剑阵」）从"持续破甲地面"换成**爆炸类**：用户实测它**放在境界 4 不够炸裂，后期剑意升级也不明显**——一个持续破甲地面，剑意加伤害也看不出来。改成一次性的密集轰炸后，**单次施法从约 5 SU 的持续伤害变成 ≈20.5 SU 的爆发**，落在境界 4 的刻度上就是"大爆发"。
  - **机制零新代码**：形态直接用现成的 `sky_drop`，它已经覆盖了要的全部表现——出生高度（天上）、`hover_time`（慢慢出来 + 停顿）、下落、落地按 `aoe_radius` 结算。
  - **各锁一敌**（`band` 列）：每支**各锁一个（尽量不同的）目标、落在它当时的位置爆炸**，天上那排黑洞则以**目标群的中轴**为心铺开 `band` 宽。这一版换过一次做法，缘由值得记下：
    - 第一版是"落点带锚在**玩家**身前"（生成宽 1200 / 落点窄 600）。画面确实铺得开，但**实测两处崩**：① 剑斜着落、观感别扭；② 更要命的是**角色边走边打时落点甩到身后**——角色每秒走 340，而下落要 1.3 秒（探出 0.8 + 下落 0.5），参照系自己就跑掉了 440 单位，一整排剑全落在空地上。
    - 换成**锚在目标身上**之后，这两个问题从构造上消失：敌人每秒只走 100~260（多数还朝角色走），1.3 秒里的位移几十到两百；而且"打谁"和"炸在哪"变成同一件事，**丢伤害这条不再存在**。
    - **打 BOSS 不丢伤害**：敌人不足时 `Picks` 会循环重复，场上只有一只时 3 支**全砸在它身上**；**聚怪收益也直接翻倍**——龙卷把怪捏成一簇时，3 支落在同一片、爆炸叠起来。它仍然是"击中谁是谁"：锁定后目标死了也照炸那个位置。
    - **黑洞仍要夹在画面内**：逻辑画布恒为 1920、角色恒在 x=330，可用横向余量只有 1460，所以 `band` 上界 1400（加载期拦）、运行期再夹。**落点不必夹**——它跟着敌人走，敌人本来就在画面里。
  - **天上的表演砍到一半**（实测反馈："滞留时间太长，落地时怪大概率已经死了，延迟感强烈"）：`hover_time 0.8 → 0.4`（探出 + 停顿）、`duration 0.5 → 0.25`（下落），全程 **1.3 秒 → 0.65 秒**。这一式是**打出去就锁定**的，表演拖得越久，"炸在已经死了的位置"的概率越高——那正是延迟感的来源。
  - **落点半径 100 → 150**（两个身位 → 三个身位）：实测"偏移后打不到人的感觉明显"。敌人是点、落点是点，但两者都在动（怪朝角色走、落点锁的是出手那一刻的位置），半径太小就会被这点相对位移甩出去。
  - **三支错时落下**（`volley_interval 0.12` + `volley_jitter 0.06`）：实测"同一时刻出现、锁定、落下，表现力和效果都不太好"。这是既有旋钮——第 i 支额外延迟 `i × 间隔`（再叠 ±抖动），于是三支有先后地探出、下落，观感从"一次齐落"变成一串。抖动还让先后次序每次都略有不同，不至于变成节拍器。
  - **新增"剑气爆炸"的击中表演**：落地时 Core 派生一个 **`Damage = 0` 的 `ground` 余韵**（寿命 `GameSession.BurstLife = 0.3` 秒），表现层按 `skill_18` 画**放射状的剑气 + 扩散冲击环 + 内核闪**。不这么做的话，天降效果在**落地当帧就被回收**（`RemoveAll(e => e.Life <= 0)`），表现层只能拍到"坠落最后一帧闪一下"，画不出真正的炸开。余韵是空伤害，**一次结算都不会走到**（寿命刻意短于 ground 的 0.6 秒结算间隔），自检里有一条断言锁住"它不造成任何伤害"。
  - **与诛仙剑阵的分工很干净**：苍穹剑陨是**在目标区域密集轰炸**（6 柄 / 间距 90 / 落点 260），**靠龙卷把怪捏在一起才炸得满**；诛仙剑阵是**无条件全屏**（`aoe_all`）。一个与聚怪耦合，一个不看位置。
  - `secondary` 置空 → **`vulnerable` 下线回到死配置**。用户明确"易伤不该占着这个技能的位置，将来由剑意授予某个技能分支"；扩展 `SwordUpgrade.effect` 属于另一轮（见第八节待办）。副作用是前排肉那条轴只剩天剑的 `execute`——轴不空，可以接受。
  - `hits` 留空（= both）是补**对空**的落点：焚天剑诀只打地面，苍穹剑陨两个层都打，空袭 / 妖潮波不再无从下手。
  - 表现：天上先浮出**黑洞**，剑锋自洞中慢慢探出、偏指着目标停一拍，再加速坠下，落地炸开一圈冲击环（`BattleView.DrawMeteorBlade`）。
- **醉仙望月步**是唯一的暴击来源，从筑基上移到元婴并同步上调（+30% / 6s → +40% / 8s）。它给的是**乘区**收益——让全队暴击一起变多，从而让"境界 4 的效率台阶"不必靠 `power` 等比膨胀来凑（[balance_ttk.md](balance_ttk.md) 第 6 节）。
- **剑气流云壁**从化神下移到元婴：它的 `cast_root` 全屏定身 + `knockback` 击退是这条轴上唯一的**推线**手段——把压上来的怪推回去，直接缓解"玩家防御端不成长"这个被 [balance_ttk.md](balance_ttk.md) 第 4.5 节硬压住的问题。30 秒冷却在元婴档仍属"偶尔来一发"的彩头。
  - **2026-10-05 实测修正**：它一度是**全场输出第一**——元婴档、功能还最杂，伤害不该这么高。`power` 76.87 → **17.9**（÷4.3），**冷却与功能一个没动**。按新口径（[skill_values.md](skill_values.md) 第三节）它落在"元婴 × 控场 0.45"的水位上，比同境界的范围技能苍穹剑陨低。注意它**溢出很高**（脆怪环境里大量打在已经在死的目标上），所以看伤害统计时它的**有效伤害**会低于它的输出水位——要看 raw（有效 + 溢出）。
- **主题：「破阵与推线」**——金丹挂状态立势（并把敌人捏到一处），元婴一次炸穿那一堆、再把压上来的战线推回去。

### 化神 · 终极（三式大招）

| # | 名称 | 类型 | 冷却 | 射程 | power | duration | 关键参数 | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 19 | **剑二十三** | buff | 40 | 950 | 1.0 | 10 | `mirror` 0.7、10s | 天光骤暗，身后凝出一道影分身，随本体同放剑诀，只是力道稍逊。 |
| 10 | 斩鬼神 | target | 15 | 950 | **106.77** | 0.9 | `targeting` highest_hp、`bonus_vs_state` 0.3 | 身前虚影浮现，一把巨剑于场上气血最厚者身后斩落，剑光过处只取一人。 |
| 15 | 诛仙剑阵 | projectile | **60** | 950 | **37.00** | 0.5 | `aoe_all` 1（`sky_drop` ×4、间距 420、高差 30、落点 700、悬停 1s） | 天光尽墨，四柄诛仙剑齐现于九霄并同时坠落，结成虚空剑阵，阵中万物俱灭。 |

- **剑二十三（影分身）**是化神档唯一的**乘区**：`kind = buff` + 次级效果 `mirror`，持续 10 秒 / 冷却 40 秒（25% 覆盖率，增益不吃攻速所以覆盖率稳定）。期间本体每放一个剑诀，身后的半透明分身就同步再放一份，伤害按继承比例打折。
  - 继承比例 = `secondary_value + 0.01 × (等级-1) + 剑意加成`，**不封顶**——全游戏最陡的一条后期成长轴。也正因如此，它那 4 行 `SwordUpgrade` 的 `value` 填的是 `0.01`（其他技能 `0.08`），两条轴才是同一个「每级 +1%」。
  - 镜像走 `LaunchShape` 而不是 `Release`：不写冷却，所以不会多发一次释放音，也不会把 `cast_root` 的全屏定身重复结算一次。
  - 分身那一式**从分身身上出发、并且晚 0.18 秒出现**。两者缺一就看不出是分身放的：`line_shot` / `line_pierce` 在起飞前停留期间要跟着**分身**走（跟着本体走会把偏移抹掉、两支剑重叠），而 `target` / `ground` / `sky_drop` 三类根本没有发射点，全靠这一拍错开才读得出来。
  - 跳过增益类与召唤类，并跳过影分身自身以免递归；`CombatEffect.Mirrored` 让表现层不再挂第二次技能名标签，也让分身出手不替本体缩冷却。
  - 完整口径（含"火海会刷新成较弱那份""击退翻倍"两条已知取舍）见 [../data/fields.md](../data/fields.md) 的「影分身」一节；不封顶带来的平衡风险记在 [balance_ttk.md](balance_ttk.md) 第 9 节。
- 另外两式都不带次级效果，各自的"额外效果"由独立旋钮承担：**选敌方式**（`targeting`）、**全体命中**（`aoe_all`）——剑气流云壁带走的 `cast_root` / `knockback` 仍是正交旋钮，别的新技能可以单独取用（见 [../data/fields.md](../data/fields.md)）。
- **斩鬼神**：`target` 类 = 延迟 `duration` 后对锁定目标结算一次；0.9 秒的延迟正是"虚影浮现 → 大剑挥落"的表演窗口，虚影与巨剑都是表现层的事，不改任何数值。**后续要"依次多个剑光"**时，把 `Picks` 的取前 n 个接上即可（现在只用 1 个），只需放宽"非 projectile 只能单发"那条校验。
- **斩鬼神还带 `bonus_vs_state` 0.3——这是全名单唯一的「利用状态」**：目标身上带着任意状态（减速 / 寒冷 / 眩晕 / 灼烧；判定里还留着 `vulnerable`，但它已随大庚剑阵下线，当前没有在役载体）时，这一剑额外 +30%。选它当载体是因为它锁的是**场上最厚的那只**，而长战斗中恰好是它身上会叠满状态——收益落在最需要的地方。它**不写任何状态字段**，只在 `Hit` 里当乘区，所以不占用"上状态"的能力（一个剑诀只有一个 `secondary` 列）。详见 [../data/fields.md](../data/fields.md) 的「利用状态」一节。
- **诛仙剑阵**：四柄剑**齐现于九霄、同时落地**（`volley_interval` 为 0，四支的起飞前停留完全一致），每柄落地都打全体，合起来就是"四剑落下、全场受创"。初始高度的差别只由表现层给（`SkyDropTop` 分层 + `spawn_jitter`），Core 不参与。
  - **2026-10-04 实测修正**：它一度占全场 **28%**（一次出手命中 **37 次**——`aoe_all` ×4 柄打全体），而 E1 表只给它记 `N1 = 4`。改法：冷却 30 → **60**、`power` 48.05 → **37**，**保留全屏抹杀**、允许它"稍微离群"（同档斩鬼神约 356 每秒，它约 900）。冷却上限用户定在 120 秒，60 秒离极限还远。
- **定位提醒**：40 秒 / 15 秒 / 30 秒的冷却在这个每秒都有输出（普攻 + 御剑术）的游戏里天然是"偶尔来一发"。但剑二十三与另外两式不同——它不直接造成伤害，而是把本体**已有**的输出整体放大一份，所以它的收益随本体变强而变强，是化神档最明显的"再上一层"。

## 六、境界主题与成长节奏

| 境界 | 主题 | 定位 |
| --- | --- | --- |
| 炼气 | 入门 | 直伤点杀 + 攻速增益 + 弧光收割，教会基础循环与增益节奏 |
| 筑基 | 续航与破排 | 剑雨铺范围、天剑横贯一整排、吸血续命 |
| 金丹 | 元素引入 | 炎 / 霜 / 雷三种状态（dot / chill / stun），聚怪（寒冰龙卷）+ 全名单唯一的真诀 |
| 元婴 | 破阵与推线 | 区域爆炸（苍穹剑陨）、暴击乘区（醉仙望月步）、全屏定身推线（剑气流云壁） |
| 化神 | 终极 | 影分身（剑二十三）、锁定最高血（斩鬼神）、四剑全体（诛仙剑阵） |

递进原则：越后期境界，技能的功能复合度越高，但单体 `power` 不简单等比膨胀，而是靠「附加状态 + 覆盖方式」变强。
