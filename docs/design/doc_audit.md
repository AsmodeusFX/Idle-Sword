> **这份文件怎么用**：它是一份**带行号的可执行清单**，不是设计文档。
> 每一条都是「某处文档说的」与「代码/配置实际的」对不上。修完一条就把它划掉。

> 下面 P0 里绝大多数都是「文档还停在旧世界」。
