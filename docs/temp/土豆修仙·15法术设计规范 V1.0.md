# 《土豆修仙》·15法术设计规范 V1.0

> **版本**：V1.0 · 2026-10-10  
> **文档性质**：15式法术的**内容与行为设计基线**；用于后续神通设计、配置制作、战斗实现和测试。  
> **覆盖范围**：五境解锁顺序、15式定位、基础行为、目标规则、形态表现、成长接口、初始CD/强度预估、工程依赖。  
> **不覆盖**：最终伤害公式、完整数值曲线、神通具体词条库、境界固有能力、神通槽数量及资源投放价格。

## 0. 文档效力与阅读约定

### 0.1 权威关系

1. 《核心成长系统认知文档.md》是修行／法术／神通／神识**职责与系统边界**的上位规范。本文件只落实其中的**法术内容**，不得改写四系统规则。发生冲突先讨论、修订上位文档，不得偷偷在代码里变更。
2. 战斗公式与出手顺序以 `docs/design/combat.md` 为准；属性定义以 `docs/design/fightattr.md` 为准；配置字段语义以 `docs/data/fields.md` 为准；数值基线及TTK以 `docs/design/balance_ttk.md`、`docs/design/skill_values.md` 为准。**不要把本文件的建议区间直接写入CSV当作最终平衡值。**
3. 《技能逻辑清单.md》是DEMO**现状快照**，只用于识别可复用的机制与工程缺口，不限制本文件的新法术形态。旧“神通”（普攻概率触发的法术）依上位文档改称**真诀**；本文所说**神通**仅指命／身／术BD系统。
4. **已经选定**的是15个法术及其基本身份；**建议试验**的是部分目标细则、CD、持续时间、基础伤害及金丹内次序。所有待议项集中在第10节，不因文档版本号是V1.0就自动视为已批准的最终数值。

### 0.2 法术统一规则

- 共 **5个境界 × 每境3式 = 15式**，境界为**炼气／筑基／金丹／元婴／化神**；“凡妖”是入道前叙事状态，不另占法术档。
- **永久习得、不设装备槽**。已习得的法术进入自动释放循环；基础释放遵循冷却、合法目标、位置与该法术特殊条件。不存在“后境界替换前境界法术”。
- **法术负责基础战斗行为，神通负责BD变化**：增弹、波次、额外折返、属性附加、死亡传染、触发循环等优先交由术／身／命神通。法术基础形态必须独立好用，不能把核心爽点留给神通补全。
- **法术习得和升级消耗法术灵韵**，不跨系统消耗神通真意、修为或神识精粹。具体价格由独立的数值与资源表承担。
- 每式拥有**元素、流派、形态**三轴标签；支持跨轴及同轴多个标签。下文的标签属于**内容建议值**，正式枚举及配置需在标签字典中统一，不因此增加第四轴。
- 法术等级成长原则上调整威力、覆盖率或既有参数；真正改写行为规则由神通负责。已有DEMO“增益类升级只提高覆盖率”的具体口径，改造前需结合该项目现状复核。
- 后期允许强烈的弹幕、覆盖与数量增长，但不得强制所有技能进化为相同的全屏AOE。

### 0.3 三档设计状态

- **【确定】**：已经经过本轮选型与反馈确认的内容和主要形态。
- **【建议】**：为了使方案可落地而提出的具体实现方式或范围，可以通过实测修改。
- **【待定】**：必须由后续数值、神通或工程讨论确认的内容，不能擅自硬编码成不可变规则。

## 1. 五境解锁顺序与阶段体验

> 每境的“第1／2／3式”是**该境界内的习得顺序**，不要求突破当刻自动获得三式。具体习得费用、节点及解锁节奏另行配置。

| 境界 | 第1式 | 第2式 | 第3式 | 该境界新的战斗体验 |
|---|---|---|---|---|
| **炼气** | **01 御剑术** | **02 妖力爆发** | **03 青元剑芒** | 前排持续击杀 → 攻速／暴击爆发窗口 → 后排与残血追踪收割 |
| **筑基** | **04 回风剑** | **05 寒冰龙卷** | **06 业火莲花** | 往返切割 → 持续减速 → 随机落点铺设灼烧区域 |
| **金丹** | **07 妖力巨口** | **08 球形闪电** | **09 冰晶碎爆** | 一口局部清怪 → 移动型持续压制 → 延时多点碎冰爆炸；同期开启神通 |
| **元婴** | **10 雷霆电矛** | **11 孢疫妖云** | **12 斩鬼神** | 高伤落矛／弱麻痹 → 长时DOT → 高血目标重斩与击杀追斩 |
| **化神** | **13 身外化身** | **14 九日凌空** | **15 诛仙剑阵** | 复制已有法术体系 → 空中持续点杀炮台 → 最终全屏处决 |

**解锁顺序说明：**

- 炼气三个位置按已确认选择**不变**。妖力爆发虽是Buff，但前期普攻仍重要；它使第一式御剑术与普攻形成明显爆发窗口，第三式再补充后排索敌。
- 筑基从“攻击路径”过渡到“战场减速”和“地面布置”，没有新增另一种大型天降重击。
- 金丹**第1巨口、第2球闪、第3碎爆**采用最近一轮推荐顺序：金丹首次习得应先有“一口挖空敌群”的即时爽感，再引入复杂持续实体。这一处排序仍可在新手／突破测试后调整，**15式名单不变**。
- 元婴先以雷矛满足境界重击幻想，再建立DOT，最后由斩鬼神提供高血目标处决与击杀连锁。
- 化神先放大已有全部法术，再获得持续点杀的太阳，最终诛仙剑阵承担最顶级的全屏终结演出。

## 2. 统一表现与目标原则

### 2.1 四个判据

每个法术必须在以下四项中至少有一个强烈、不可替代的特征：

1. **攻击对象**：前排最近、后排／低血、高血／Boss、密集敌群、目标所在区域、全场等。
2. **运动方式**：空中直射、弧线追踪、往返、缓慢推进、位置固定、目标跟随、悬空随行等。
3. **时间结构**：高频连续、爆发窗口、延迟爆炸、持续DOT、周期锁定、长CD终结等。
4. **清怪方式**：逐只点杀、贯穿扫排、慢速压线、地面覆盖、击杀追斩、全屏条件抹杀等。

### 2.2 与世界移动的关系

《土豆修仙》是持续向右推进的横版自动战斗。必须区分三类攻击实体：

- **角色随行型**：御剑术的发射阵列、妖力爆发、身外化身、九日凌空。角色继续前进时仍应维持有效发射位置。
- **世界位置型**：业火莲花、雷矛的落地余韵、冰晶碎爆的延时爆点、妖力巨口。释放时锁定世界区域；过期、离开有效战区后按统一规则回收。
- **移动交战型**：球形闪电、寒冰龙卷、回风剑、剑芒。需要确保移动过程中不会普遍失去有效目标；追索范围、边界与失效回收另有统一约束。

### 2.3 派生攻击与事件归属

基础法术、持续攻击、Buff时间轴派生Effect、神通触发的额外攻击，应有明确的**原始来源、当前来源、派生深度与触发资格**。必须防止复制再复制、击杀无限追斩、弹丸分裂无限递归。具体结算顺序沿用战斗主文档，本文不另定义新伤害公式或乘区。

## 3. 炼气：先点杀，再形成弹幕

### 01 御剑术｜剑系｜空中列阵、微俯角直射

**定位【确定】**：入门高频输出；主要处理面前最近的敌人，后期升级为浮游炮式多波次飞剑弹幕。

- **释放形态**：角色**左上方空中**浮现一排平行排列、剑尖朝敌人的飞剑；短暂成阵后，沿基本直线向前射出。允许每柄剑依据当次目标位置做小角度**向下修正**，保证不普遍从怪物头顶掠过；发射后不持续转弯追踪。
- **目标／命中**：优先最近合法敌人、沿飞行路径先碰到的目标。多剑允许同一目标或前排多个目标被击中；与剑芒的低血追踪明确区分。目标在发射前选择，弹道的实际首碰撞判定仍有效。
- **基础体验**：短间隔“一阵剑浮现 → 一阵剑齐射”；无须复杂长前摇。**【建议】**初始2～3剑、一轮齐射。
- **神通接口**：飞剑数量、阵列层数、发射波次、波次间隔、穿透、附加副属性、命中衍生攻击。特别保留**连续浮现—齐射**的浮游炮式演化。
- **护栏**：它不应转型为持续大弧度追踪，也不应像剑雨一样从高空垂直落地；数量很大时阵列要有屏幕高度限制和弹丸性能限制。
- **建议标签**：元素=无／流派=剑法／形态=弹道、直射、多弹。

### 02 妖力爆发｜妖系｜全角色爆发Buff

**定位【确定】**：前期强化普攻的关键法术；中后期强化所有攻击与法术的阶段性爆发窗口。

- **释放形态**：土豆妖短时间释放妖力，身体妖纹与灵气显著变化；有明确的启动和结束反馈。
- **基础效果**：在限定持续时间内提高**普攻速度**与**暴击率**。此处的暴击加成属于角色通用属性；已有法术越多，暴击Buff的整体价值越大。
- **神通接口**：普攻触发额外法术／攻击效果、暴击缩短其他法术CD、Buff覆盖率与持续时间强化、爆发期间触发额外攻击等。
- **护栏**：暴击缩CD、普攻派生攻击等**不预装**为基础技能全部规则，主要交由神通；Buff本身不得成为新伤害乘区。
- **建议标签**：元素=无／流派=妖术／形态=自身增益、爆发窗口。

### 03 青元剑芒｜剑系｜弧线追踪、残血收割

**定位【确定】**：与御剑术互补的第二套高频攻击；优先攻击低血目标，也应具备触达后排目标的能力。

- **释放形态**：多枚细小剑芒以不同弧度飞出，在空中绕曲线追向各自目标，强调飘逸、密集、快速的弹幕视觉。
- **目标／命中**：基础以**低血量优先**为明确规则；面向后排的优先级如需识别“射手／后排单位”，应由正式敌人标签或目标规则提供，不能默认“低血=后排”。
- **基础体验**：多枚剑芒同时／错时追击；选定目标后可持续追踪，死亡改索可复用既有弧线追踪机制。
- **神通接口**：剑芒数量、弧线跨度、改索次数、跨目标追猎、副属性、收割触发。
- **护栏**：不转化成御剑术那种平行直射；即使数量膨胀，也保留追踪及目标分布的特征。
- **建议标签**：元素=无／流派=剑法／形态=追踪、多弹、收割。

## 4. 筑基：改变攻击路径、怪物节奏与地面空间

### 04 回风剑｜剑系｜贯穿与折返切割

**定位【确定】**：少量有分量的飞剑来回穿过敌群；与剑芒的多弹追踪、御剑术的直射完全不同。

- **释放形态**：飞剑沿横向穿过敌人，到达折返点后反向飞回。**基础已有1次折返**，即出去和回来均能切割敌人。
- **目标／命中**：路径上所有合法敌人都能受到切割；飞剑的轨迹与折返点围绕有效战斗区域设定，不因目标死亡而立刻消失。
- **神通接口**：增加折返次数、单次路径宽度、折返速度、折返点特殊攻击、附加副属性。
- **护栏**：折返次数有限且与飞剑寿命统一；避免过度提高弹数而失去“一柄剑反复切割”的主形态。
- **建议标签**：元素=无／流派=剑法／形态=贯穿、往返、多段。

### 05 寒冰龙卷｜霜系｜持续减速、缓慢推进

**定位【确定】**：范围持续伤害与敌人速度控制，不再承担击退／吸附。

- **释放形态**：冰雪龙卷在战斗区域出现，并缓慢向前移动；范围内敌人受到周期性霜伤与减速。
- **基础效果**：**减速但不推怪**。怪物位置不会因为龙卷每次结算而被推走。对Boss的减速应用按现有怪物规则处理。
- **神通接口**：龙卷数量、持续时间、范围、移动方向、减速强化，特殊神通**冻结／定身**；“屏幕两侧龙卷向中间汇合”仍是候选特殊形态，**不属于基础效果**。
- **护栏**：冻结不能天然成为高频永久控Boss；不得悄悄恢复早期方案的推怪效果。
- **建议标签**：元素=霜／流派=霜法／形态=持续、范围、减速、移动场。

### 06 业火莲花｜炎系｜随机撒种、地面持续灼烧

**定位【确定】**：地面铺场的主要法术。核心是多个火莲不断铺出灼烧区域，而非首段爆炸。

- **释放形态**：向当前有效敌群所在的前方区域**随机抛洒莲种**；种子落地后成长为火莲，地面形成可见火场并周期灼烧敌人。
- **基础效果**：以**DOT为主体**，**不强调首次爆炸伤害**；初始可一次投下多枚莲种。随机落点需限定在有战斗价值的区域，避免大批种子落空。
- **神通接口**：种子数量、播撒范围、火场持续时间、重叠规则、持续前铺、火焰不灭、副属性。
- **“火焰不灭”候选**：持续向角色前方铺新火莲，旧效果离开有效区域时清理；呈现永续燃烧感，不允许实例数量无限积累。
- **护栏**：基础不具备妖云那样的**死亡感染传播**；多个火场同时覆盖一目标时的伤害叠加与上限须统一定义，避免弹量增加同时造成不可控的单体多倍伤害。
- **建议标签**：元素=炎／流派=炎法／形态=地面、持续、DOT、多点布置。

## 5. 金丹：强烈的局部清场、持续实体与延时爆炸

### 07 妖力巨口｜妖系｜密集区生成、瞬间高伤

**定位【确定】**：金丹的即时震撼技能；“植物大战僵尸式食人花”的巨口，快速在敌群中挖出一块真空。

- **释放形态**：直接在敌人密集处从地面／妖藤中长出大口，张口后猛烈闭合，产生**单次极高的小／中范围伤害**。
- **目标选择**：优先有效目标区域内的**敌人密度高点**，而非永远固定在角色前方；敌人稀少或单Boss时仍能正常咬合并造成高伤。
- **基础效果**：**纯伤害，无直接斩杀／吞噬即死判定**。看到区域被清空，应是因为本次伤害确实杀死敌人。
- **神通接口**：额外巨口、多个不同位置生成、咬合次数、作用半径、附加状态或副属性。
- **护栏**：无需强制吸怪；不与冰龙卷争夺移动控制；多个巨口的目标分配要避免不必要的完全重叠。
- **建议标签**：元素=无／流派=妖术／形态=范围、爆发、定点召现。

### 08 球形闪电｜雷系｜巡航快移／交战慢移

**定位【确定】**：可以持续存在并向前压线的高伤雷球；它并非普通慢速子弹。

- **释放形态**：大型雷球从角色前方出现，向右寻找目标；进入敌人附近后降低前进速度，并向周围目标持续释放电弧、周期造成伤害。
- **移动规则**：**空载高速巡航；接敌低速推进与放电；附近敌人被清除后重新加速。**即使遇到高血Boss也不应无限停住，允许低速穿过或设定交战停留上限。角色持续向前移动时，不应大范围将雷球甩在屏幕后方。
- **目标／命中**：沿移动通道与附近敌人交战；对Boss可持续电击，对怪群可逐段推进。
- **神通接口**：雷球数量、持续时间、球体半径、电弧攻击目标、放电频率、球体间连线、副属性。
- **护栏**：不能和寒冰龙卷都以强击退为主要用途；巡航不等于无敌穿怪，实际伤害要按交战判定执行。
- **建议标签**：元素=雷／流派=雷法／形态=移动实体、持续、多段、范围。

### 09 冰晶碎爆｜霜系｜多枚冰晶、延迟小范围爆裂

**定位【确定】**：金丹补足的“延时局部爆炸”。原玄冰镜阵退回创意储备，不占15式。

- **释放形态**：向有效敌群区域抛出**多枚冰晶**；经过短暂延迟，冰晶各自爆裂，向周围炸散晶体碎屑，造成多处明确的小范围爆炸。
- **基础效果**：主要伤害来自**延迟爆炸**；碎冰飞散具有清晰视觉冲击，但其是否另外计算真实弹丸伤害**待定**。基础版本可先只做爆炸伤害，以免与青元剑芒混淆。
- **神通接口**：冰晶数量、爆炸半径、爆炸延迟、二次爆裂、碎片变成真实弹丸、碎片穿透／附加冻结。
- **护栏**：与业火莲花不同，它是**短延时爆炸**，不生成持久地面DOT；与剑芒不同，它不是施放时就发出的持续追踪弹幕。
- **建议标签**：元素=霜／流派=霜法／形态=延迟、范围、爆炸、多点。

## 6. 元婴：强打击、强DOT与关键目标处决

### 10 雷霆电矛｜雷系｜落矛重击、留矛弱控制

**定位【确定】**：元婴的大招型落地冲击，强调第一下大伤害，随后持续麻痹和少量放电。

- **释放形态**：空中凝聚一柄大型雷电长矛，向敌群位置猛然刺落；落点是**小范围**，并非单体攻击。雷矛短暂插在地面，向附近敌人发出周期性电弧。
- **伤害结构**：**落矛是绝对主伤害**；留矛的周期电击伤害较低，主要体现麻痹、控制与视觉余韵。
- **神通接口**：额外雷矛、落点数量、落地冲击范围、留矛持续时间、放电目标与频率、雷矛间电弧。
- **护栏**：留矛不能退化成第二个九日持续高输出炮台；对Boss的麻痹覆盖／控制抗性需遵从战斗系统限制。
- **建议标签**：元素=雷／流派=雷法／形态=天降、范围、爆发、持续状态。

### 11 孢疫妖云｜妖系｜附着感染、长时DOT

**定位【确定】**：元婴的主要感染型持续伤害；高血怪及Boss时仍能独立发挥价值。

- **释放形态**：孢疫妖云出现在有效敌群附近，缓慢漂浮／覆盖敌人，感染目标；目标离开妖云后，孢疫仍持续一段时间造成DOT。
- **基础效果**：**以DOT为主，首段直接伤害很弱或没有**。基础版**没有死亡传播**，击杀传播由术神通解锁。
- **神通接口**：DOT持续时间、感染覆盖、目标感染数量、死亡时感染传播、死亡时生成新妖云、附加副属性。
- **护栏**：不因无法快速击杀Boss而失去作用；不要和火莲共享“固定地面灼烧”身份；重复施加与DOT归属须遵守统一的Buff与伤害规则。
- **建议标签**：元素=无／流派=妖术／形态=DOT、感染、持续、范围。

### 12 斩鬼神｜剑系｜高血锁定、高伤重斩、击杀追斩

**定位【确定】**：高血量、精英／Boss重点打击；与低血收割的剑芒恰好相反。

- **释放形态**：锁定高血量合法目标，巨型剑影在目标附近短暂显形，随后造成一次极高的**单体伤害**。
- **基础目标规则**：优先高血量目标／强敌，不改成低血量优先。**【待定】**“当前HP最高”还是“最大HP最高”，以及精英/Boss的额外优先级、是否无视一般射程，需要在目标系统中统一确认。
- **基础特色【建议采纳】**：若本次斩鬼神**直接击杀**目标，立即再寻找一个合法目标额外追斩**1次**；首刀没击杀则本次结束。追斩属于**同一次施法的派生攻击**，不重置冷却。
- **神通接口**：追斩次数上限、锁定高血目标的规则、击杀后寻找新目标、单体爆发条件、附加副属性。
- **护栏**：不是无条件直接斩杀；必须有连斩次数上限，不能依靠低血怪无限连锁到全屏，侵占诛仙剑阵的终结定位。
- **建议标签**：元素=无／流派=剑法／形态=单体、重击、击杀追斩。

## 7. 化神：法术复制、持续灼烧点杀与最终全屏终结

### 13 身外化身｜妖系｜增加独立施法主体

**定位【确定】**：化神第1式，玩家此前积累的法术越多、神通机制越完整，其体验越强。

- **释放形态**：土豆妖召出一个或多个妖魂化身，短时间模仿本体释放法术，形成多施法者同屏战斗的视觉。
- **基础效果**：**【建议】**初始1个化身，在限定时间内以部分继承伤害复制符合条件的攻击法术；不复制自身，不重复施加妖力爆发等Buff。
- **神通接口**：化身数量、持续时间、继承倍率、复制的法术类别／标签、额外间隔或施法行为。
- **护栏**：化身数量必须有上限；复制出的攻击不得再次触发自身复制；特殊处决与超强控制不默认完整复制，诛仙的秒杀逻辑尤其必须单独限制。复用现有分身复制实现的可行部分，但不照搬已退役参悟成长。
- **建议标签**：元素=无／流派=妖术／形态=分身、增益、复制。

### 14 九日凌空｜炎系｜角色随行天空炮台、持续射线点杀

**定位【确定】**：化神的大型**持续单体点杀**法术，多个太阳各自锁敌；不做全屏扫荡型光束作为基础。

- **释放形态**：天上出现**1个太阳**，射出**1条持续火焰射线**锁定目标，按持续伤害节奏灼烧；神通可以增加太阳数量，每个太阳独立锁定、转换目标。只有Boss时多个太阳可以集火同一目标。
- **与角色移动的关系【确定方向】**：太阳应当**随角色／镜头一起前进，不作为固定在旧战斗位置的世界炮台**。视觉可呈远景天空层、略带缓动；但目标位置、光束及命中判定必须在真实战斗坐标中计算。角色移动时太阳不应自动离屏失效。
- **攻击逻辑**：太阳独立寻找有效目标并持续照射；目标死亡后较快重新索敌，没有目标则随角色前进等待。**【建议】**太阳持续照射同一目标可以进一步强化灼烧，但这不是基础规则，留给神通或数值讨论。
- **神通接口**：太阳数量、锁定目标分配、射线数量、灼烧增强、扫荡射线形态、太阳间光网、副属性。
- **护栏**：基础九日不是诛仙式全屏AOE，也不是单次天降爆炸；视觉相对跟随不应导致逻辑命中坐标随镜头错误移动。
- **建议标签**：元素=炎／流派=炎法／形态=持续、锁定、炮台、DOT。

### 15 诛仙剑阵｜剑系｜最高级全屏条件秒杀

**定位【确定】**：最终习得、演出价值与单次战斗价值最高的法术；极长CD、全屏巨剑降临、条件清屏。

- **释放形态**：多柄巨剑于天穹列阵，强烈的蓄势／压迫演出后同时降临，覆盖全战场。
- **基础伤害**：全场合法敌人均承受极高伤害。**非Boss敌人**若生命比例处于指定阈值以下，可直接被抹杀；不符合阈值仍受到正常高伤。
- **Boss规则**：**绝不直接秒杀Boss**。对Boss造成单独约束的高额／固定伤害，具体固定值、封顶还是替代计算**待数值方案确认**。
- **自动释放【建议】**：为了避免极长CD被一只残血怪浪费，可设置法术自身的释放门控，例如敌人数达到阈值或出现精英／Boss；属于技能的特殊释放条件，不能擅自推进神识v1的通用战斗AI。
- **神通接口**：巨剑数量、清场阈值、施放条件、特殊附加属性、阵落效果。但任何扩展都不能让诛仙脱离终局技能的演出定位。
- **护栏**：极长CD；处决只能作用于合法非Boss目标；分身／额外释放必须防止复制无限清屏与死亡事件递归。
- **建议标签**：元素=无／流派=剑法／形态=全屏、爆发、处决、长冷却。

### 8.2 强度哲学

- **炼气**：御剑与剑芒保证持续产出；妖力爆发提供清晰的阶段性收益，前期普攻不可被过早淘汰。
- **筑基**：新法术必须有自己的完整体验；回风初始已有折返、冰龙卷初始就能减速、火莲初始就是多点DOT。
- **金丹**：巨口首次获得就该“一口挖空”普通怪的一片区域；高威力由较长CD支付成本。球闪与碎爆分别提供持续和延迟节奏。
- **元婴**：雷矛第一击震撼；斩鬼神首斩就能重创强敌，击杀追斩不应被弱基础伤害长期锁住；孢疫妖云在Boss长战斗也必须有效。
- **化神**：化身初次获得就改变同屏施法规模；单太阳九日也要明显点杀；诛仙是单次战斗演出的最高峰，长CD与条件释放给DOT留下表现时间。
- **整体**：放置后期可出现输出溢出，不要求每个技能对每种敌人保持一样的输出份额。必须分别测试低压清怪、高压推进、精英／Boss长战斗。

### 8.3 自动释放与覆盖率

- 基础法术仍遵循“冷却就绪＋合法目标”原则，不因本文直接开放神识的战斗AI。
- 超长CD特殊大招可以设计**法术自身的最小释放条件**（例如诛仙敌人数门槛），但需要对应配置、文案和测试，不能暗中硬编码。
- 持续输出法术尤其要检查角色推进、目标死亡、世界边界、目标索敌更新对有效DPS的影响；不能只看静态木桩的理论伤害。
- Buff覆盖率、太阳照射覆盖率、DOT实际持续时间和球闪的交战／巡航占比，应进入后续期望模型或实测观测项。

## 9. 工程落地映射：需要扩展哪些Skill逻辑

### 9.1 现有可复用机制

当前DEMO使用 `SwordSkill`／`SkillEffect`／`SkillBuff`／`SkillBuffTimeline`／`SkillBuffTrigger` 五表。其可复用能力包括：

- 弹道（直线、贯穿、弧线追踪）、错时多弹、天降、目标锁定及失去目标后的部分改索。
- 地面持续效果、DOT、减速／寒冷、麻痹、盾、攻速与暴击Buff。
- 伤害事件、出手快照、现有 `on_crit`／`on_skill_cast` 触发器，以及分身复制的一部分链路。

**保留这五层的职责结构，但不要被当前枚举及单主效果限制锁死新法术。** 本文的技能形态是目标状态；具体是否新增表，需先根据架构拆分成基础行为和动态神通修正。

### 9.2 按法术判断的工程增量

| 法术／组 | 可复用 | 明显需要新增或检查的能力 |
|---|---|---|
| 御剑术 | `projectile_count`、直线弹道、错时 | **角色左上方固定相对阵列**、每柄微俯角、波次与多排视觉、前排首碰撞 |
| 妖力爆发 | `haste`／`crit_reduce`现有能力 | **复合自身Buff**；攻速与暴击共同生效；爆发期文案与特效 |
| 青元剑芒 | `arc_homing`、`lowest_hp`、改索 | 后排目标若纳入真实规则需敌人角色标签／优先级；大量弹幕性能 |
| 回风剑 | `line_pierce` | **折返轨迹**、同一实体多次穿透计伤、折返次数与寿命 |
| 寒冰龙卷 | `ground`、`chill` | 移动区域效果、不推怪；未来神通冻结需要与控制抗性结合 |
| 业火莲花 | `ground`、`dot`、`sky_drop`或地面生成 | **随机多点播种**、生长时序、多个火场同源重叠／回收 |
| 妖力巨口 | 范围扫描、延时攻击 | **敌群密度选位**、瞬时合口范围伤、巨口多点选位 |
| 球形闪电 | `auto_attack`／周期伤害部分 | **巡航／交战双速状态机**、移动实体持续放电、目标变化与离屏处理 |
| 冰晶碎爆 | 延时、范围攻击 | **多个定点冰晶延迟爆炸**；碎片实体如产生真实伤害，另加派生Effect |
| 雷霆电矛 | `sky_drop`、`stun`、持续时间轴 | **落矛重击＋留矛弱放电**的组合效果；对Boss控制限制 |
| 孢疫妖云 | `dot`、持续场 | **移动覆盖／目标附着感染**；死亡传播**先留神通接口**；DOT重置口径 |
| 斩鬼神 | `target`、`highest_hp`、单体高伤 | **`on_kill`／直接击杀判定**、最多1次追斩、目标重选、递归深度护栏 |
| 身外化身 | `mirror_cast` | **化身主体数量与生命周期**、复制类别限制、复制来源追踪、特殊技能限权 |
| 九日凌空 | 定时攻击／选敌框架 | **随角色的太阳实体**、持续目标锁定射线、每太阳独立索敌与周期灼烧 |
| 诛仙剑阵 | `aoe_all`、`sky_drop` | **按敌人类型的条件处决**、Boss独立结算、可选自身释放门控、复制限制 |

### 9.3 公共基础设施（优先于逐个特判）

1. **动态法术修正层**：所有神通修改应在运行时形成最终Skill／Effect参数，不应改写基础CSV。支持数量、频率、弹道、目标、标签、额外效果等白名单式变化。
2. **通用战斗事件**：补齐 `on_hit`、`on_kill`、`on_damage`、`on_enemy_death` 等确实有消费点的事件。斩鬼神的追斩、妖云的死亡传播神通和未来命中次数机制都依赖这层。
3. **攻击来源／派生深度**：明确定义法术本体、Buff触发、神通附加、化身复制、斩鬼神追斩、碎片二次攻击的派生资格及触发上限，避免无限递归。
4. **运动／坐标通用规则**：将随行实体、世界场、移动交战实体、可视区域／战斗区域回收分开实现；九日和球闪是典型测试载体。
5. **多阶段法术表达**：支持“一次施法，多个独立阶段”——如落矛→留矛、撒种→火场、冰晶→爆炸、雷球巡航→交战，尽量以可组合Effect与时间轴／状态机表达。
6. **标签与文案**：新增三轴标签配置、读取、神通过滤；新增枚举必须同时添加消费逻辑、合法值校验、可读文案与自检，不允许静默失效。
7. **属性归属**：`fightattr` 保留通用攻击、暴击、攻速、冷却、生存等属性；火法增伤／某法术额外弹丸／击杀追斩次数等不应一律新增固定fightattr列。实际新增属性数量需读取最新 `fightattr.md` 后再裁定。不得为神通新增独立伤害乘区。

### 9.4 从旧在役15式迁移的注意事项

- 旧技能名与新15式**不能按旧ID机械替换**。需明确新技能稳定ID、旧Skill／Effect／Buff引用、配置映射、解锁顺序与存档迁移。
- 旧仙风云体与醉仙望月的攻速、暴击行为可用于新**妖力爆发**；旧**剑二十三**的复制功能可用于**身外化身**；原御雷真诀“普攻概率触发”的**真诀**语义不得和新的BD“神通”混淆。
- 旧参悟／剑意相关效果与货币**按核心认知文档删除**；不得为了保留旧机制，重建已否决的 `SwordUpgrade` 成长线。
- `SwordSkill` 的 `kind`、`effect_ids`、`buff_ids`、`realm_id` 与旧测试中“每境3式、固定id集合”等约束都要同步迁移；配置更新后运行既有自检、战斗对账和Godot冒烟测试。

### 10.2 测试必须覆盖的战斗情境

- **新手少技能**：仅御剑术；御剑+妖力爆发；完整炼气三式。检查普攻价值、Buff阶段的视觉差异、直射与追踪分工。
- **稀疏低血怪**：避免巨口、碎爆、火莲完全打空；观察诛仙是否在不值得时立刻释放。
- **密集怪群**：验证火莲重叠、巨口选位、回风穿透、球闪推进、雷矛覆盖、诛仙清屏。
- **远程后排敌人**：御剑优先清前排，剑芒能否产生后排／残血收割效果；目标改索稳定性。
- **高血Boss／长期卡点**：九日持续照射、妖云DOT、球闪有效接敌、斩鬼神高伤、身外化身复制与Boss特殊控制／处决边界。
- **高战力碾压**：直伤快速清怪导致DOT贡献降低是允许的；检查DOT法术仍有可见存在感以及后续神通构筑价值。
- **多神通满配压力**：大量飞剑波次、额外回风、多个雷球／太阳／巨口、复制与死亡传播同时触发时，不无限递归、不泄漏实例、不误归因伤害。
- **角色连续移动**：九日始终在可用攻击位置；球闪能追赶交战线；火莲旧场合理回收；任何重要法术不因镜头推进静默失效。

## 11. 本版本裁定摘要

**固定编制：**

- **炼气**：御剑术 → 妖力爆发 → 青元剑芒。
- **筑基**：回风剑 → 寒冰龙卷 → 业火莲花。
- **金丹**：妖力巨口 → 球形闪电 → 冰晶碎爆（本版采用推荐内序）。
- **元婴**：雷霆电矛 → 孢疫妖云 → 斩鬼神。
- **化神**：身外化身 → 九日凌空 → 诛仙剑阵。

**关键辨识度：**

- 御剑术 = **左上空中平行列剑，微俯角直射，未来可多波次浮游炮**；青元剑芒 = **低血优先的弧线追踪**。
- 回风剑 = **一次基础折返**；寒冰龙卷 = **减速不推怪**；业火莲花 = **随机撒种、地面DOT，不强调首爆**。
- 妖力巨口 = **密集区域一口高伤，不自带秒杀**；球闪 = **空载快移、交战慢移**；冰晶碎爆 = **多点延时爆炸**。
- 雷霆电矛 = **小范围落地重击＋弱持续麻痹**；孢疫妖云 = **DOT为主，死亡传播由神通赋予**；斩鬼神 = **高血量单体重击，击杀后可额外追斩**。
- 身外化身 = **全法术复制并有递归／数量限制**；九日凌空 = **随行太阳、持续锁定点杀**；诛仙剑阵 = **最长级别冷却、最高级别全屏条件终结**。

**最重要的设计原则：**法术必须在未构筑时就有独特、有价值的攻击形态；神通不负责补齐基础功能，而是改变法术的**数量、时空形态、触发关系、副属性和战斗循环**。由此使相同15式法术在不同神通BD下产生不同战斗体感。
